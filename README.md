# Cardstock — deploy mirror

Built site for **Cardstock**, a camera-first TCG scanner & collection portfolio PWA
(Magic · Pokémon · Yu-Gi-Oh): point your camera at a card, see what it's worth,
track your collection like a portfolio, build decks.

**Live: https://corruptfun.github.io/CardStash/**

This repo carries build output only (`gh-pages` branch). Point your phone at the
link above and add it to your home screen — camera scanning, offline shell and
local-first storage all work from there.
